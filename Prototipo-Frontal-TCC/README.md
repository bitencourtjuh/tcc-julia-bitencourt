# Protótipo Frontal — TCC

Versão enxuta do protótipo frontal para apresentação e demonstração no TCC.

## Executar

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
npm run preview
```

Os dados e operações de login, upload, extração, blockchain e validação são simulados localmente em `src/app/services/api.ts`; não é necessário backend para demonstrar o protótipo.


## Direção visual
Interface redesenhada com identidade editorial inspirada na apresentação do TCC: azul-marinho, off-white e dourado, com foco em confiança, Direito, IA e automação documental.
