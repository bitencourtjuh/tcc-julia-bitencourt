  <h2 style="color:#333;"> --- Sobre o Projeto</h2>
  <p>
    Este projeto tem como objetivo desenvolver uma solução tecnológica para a 
    <strong>digitalização, organização e gerenciamento</strong> de documentos de cartórios, 
    promovendo mais eficiência, segurança e acessibilidade às informações.
  </p>

  <p>
    A proposta visa substituir processos manuais por um sistema digital, permitindo o 
    armazenamento estruturado dos dados, busca rápida de registros e redução de erros operacionais. 
    Além disso, contribui para a preservação de documentos físicos e otimiza o atendimento ao público.
  </p>

  <p>
    Desenvolvido como <strong>Trabalho de Conclusão de Curso (TCC)</strong>, aplicando conceitos de 
    desenvolvimento de software, banco de dados e usabilidade.
  </p>
